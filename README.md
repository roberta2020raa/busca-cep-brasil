# BuscaCEP Brasil

## Descrição
Um buscador de endereços brasileiros que permite encontrar uma rua pelo CEP ou pesquisar CEPs informando o endereço.
## Objetivo
Facilitar a consulta de CEPs e endereços brasileiros, permitindo que os usuários encontrem informações a partir de um CEP ou de um endereço informado.
Oferecer uma experiência simples, rápida e responsiva, permitindo consultas em computadores, tablets e celulares.
